# Pixel Store – Práctica de depuración

Página web de un negocio ficticio. **Tiene un fallo**: encuéntralo y corrígelo siguiendo el enunciado de la práctica.

## Estructura

```
index.html
css/
  style.css
```

## Cómo debería verse la página

- **Cabecera** de color oscuro con el nombre "Pixel Store" a la izquierda y el menú (Ofertas, Torneos, Contacto) en horizontal a la derecha, en blanco, sin viñetas ni subrayado.
- **Portada** de color con texto blanco centrado y un botón de color destacado "Ver ofertas".
- **Ofertas**: tres tarjetas blancas (Pack retro, Mando inalámbrico, Torneo sábado), con bordes redondeados y sombra, colocadas una al lado de otra.
- **Torneos** sobre un fondo suave, centrado.
- **Pie** de color oscuro con la dirección centrada.
- Tipografía sin serifa (Arial) en toda la página.
